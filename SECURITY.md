# Security reporting

Please send suspected security vulnerabilities privately to
[panoptos@ruverse.ai](mailto:panoptos@ruverse.ai). This gives the maintainer an
opportunity to investigate and prepare a fix before details become public.
Do not post exploit details in a public issue while a report is unresolved.

Include the Panoptos and macOS versions, a description of the impact, and
minimal reproduction steps where possible. Remove license keys, credentials,
personal window titles, and other private data from logs and screenshots.
Never send passwords, signing keys, or other secrets.

Coordinate public disclosure with the maintainer after a fix is available.

For ordinary bugs and feature requests, use
[GitHub Issues](https://github.com/RUverse/panoptos/issues).
