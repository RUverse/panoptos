# Panoptos for Linux

An approachable Linux desktop built on Omarchy, with persistent window zones,
window stacks, and controls that work with both the mouse and keyboard.

The first version targets Mac and Windows users who are new to Linux. It builds
on Omarchy's existing system integration and adds the Panoptos desktop experience.

## Project status

Planning stage. This repository does not yet contain an Omarchy source import,
a working Linux desktop, or an installation image.
